Steps to publish your own crate:

bash# 1. login with github

```bash
cargo login
```

# 2. add metadata to Cargo.toml

```toml
toml[package]
name        = "my_awesome_crate"
version     = "0.1.0"
edition     = "2021"
description = "A short description"
license     = "MIT"
repository  = "https://github.com/you/my_awesome_crate"
```

bash# 3. publish

```bash
cargo publish
```

# 4. update version in Cargo.toml then republish

```bash
cargo publish
```

/// Adds two numbers together
///
/// # Examples
/// ```
/// let result = my_crate::add(2, 3);
/// assert_eq!(result, 5);
/// ```
pub fn add(a: i32, b: i32) -> i32 {
    a + b
